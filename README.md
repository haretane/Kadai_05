## ②課題内容（どんな作品か）
タイトル：「昨日の気温はどうだっけ？」

一般的な天気予報は、今日〜明日→１週間くらいが表示されます。<br>
あとは、最低気温最高気温がプラマイどれくらいか。<br>

 でも、季節の変わり目って、その情報だと「昨日や一昨日に比べて寒いのか暑いのか」ってわかりませんよね？服が選びづらいですよね？そうですよね！？？そうなんです！！<br>
ということで、今日明日にくわえ、３日前までの時間毎の気温がわかるアプリを開発しました。

※場所の登録を３箇所まで登録できます。登録値を呼び出すときは「登録」。登録するときは今調べた地名のまま、「登録」ボタンを長押。<br>
※APIはopen-meteo　というサービスを使ってますが、、、海外のサイトなので、検索でうまく地名が出ない場合があります、笑（「◯◯市」と検索すると確実に出る）

## ⑤工夫した点・こだわった点

・各日の時間帯ごとの気温を比較できるようにしたかったので、カードでの表示とテーブル（TR・TD）を組み合わせました。<br>
・テーブルは表示された瞬間は7時ー13時を表示。上下左右のスクロールで、他の時間や曜日にうつれる。
・画面レイアウトはスマホを基調にしてます。


## ⑥難しかった点・次回トライしたいこと（又は機能）

OpenWhether　だと過去のデータが有料だっので、「Open-Meteo」というapiを使用しました。<br>
しかもこのapi、住所検索もできちゃう、ということで喜んで使用したのですが、日本の地名検索が弱く、、、（例えば「原宿」で検索してもヒットしない。「町田」と検索すると香川県町田が出てくる、など）<br>
解決策として、住所検索は切り離して、国土地理院 のapiを組み込むなどの解決策が考えられます。
（ですが、有料でもいいなら、日本の事ならやはり、ウェザーニュースや日本気象協会などの日本国内のapiはやはり強いなと思いました）
